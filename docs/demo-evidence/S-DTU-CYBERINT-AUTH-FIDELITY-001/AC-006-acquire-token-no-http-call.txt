--- WHAT THE TEST ASSERTS ---

1. Constructs StaticCookieAuthProvider::new_with_resolver("cyberint",
     Arc::new(NotFoundCredentialResolver))
   (NotFoundCredentialResolver always returns CredentialResolutionError::NotFound)
2. Calls acquire_token(&spec, &client_id).await
3. Asserts result.is_err()
4. Asserts error contains "E-AUTH-005"
   (credential not found path — E-AUTH-005 returned without any HTTP call)

No HTTP server is instantiated in this test — there is no possibility of an HTTP
call being made. The test also exercises the error path to confirm E-AUTH-005
is returned with the correct error code.

--- STRUCTURAL PROOF: no HTTP client in StaticCookieAuthProvider ---

File: crates/prism-spec-engine/src/auth_provider.rs

pub struct StaticCookieAuthProvider {
    sensor_id: String,
    resolver: Arc<dyn CredentialResolver>,
}

The struct has NO reqwest::Client field and imports NO reqwest types. The
INV-COOKIE-001 invariant is enforced structurally: there is no mechanism by
which acquire_token() could issue an HTTP request.
